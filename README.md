# CS2D ModHub — учебный WPF-макет

Автор лабораторной: Дорощенок. Тема: демонстрационный репозиторий модификаций CS2D.

## Открытие

1. Windows: Visual Studio 2019/2022 с компонентом «Разработка классических приложений .NET» и пакетом разработчика .NET Framework 4.7.2.
2. Открой `CS2D_ModHub.sln` (или `CS2D_ModHub.csproj`).
3. Выбери «Сборка → Собрать решение», затем F5.
4. Если Visual Studio предлагает установить targeting pack .NET Framework 4.7.2, установи его.

## Структура

- `MainWindow` — контейнер Frame и шапка.
- `Nav.cs` — переходы между страницами.
- `Pages/HomePage` — четыре кнопки основного меню.
- `Pages/ModPage` — список вымышленных модов, поиск, категории.
- `Pages/ModManPage` — выбранный мод: название, условная обложка, версия, автор, описание, кнопка скачивания.
- `Pages/OpPage` — два фильтра. Состояние сохраняется в памяти в пределах одного запуска.
- `Pages/ComPage` — форма отзыва / поддержки с демонстрационным подтверждением.
- `Models` — демонстрационные данные каталога.

## Ограничения

Это прототип для учебного отчёта, не настоящий репозиторий. Никаких файлов с модами нет, скачивание не выполняется; сообщения никуда не отправляются. Все записи о модах вымышленные. Условные обложки представлены текстовыми плитками. Интернет и сторонние библиотеки не требуются.

Проверка сборки в Visual Studio/Windows в среде подготовки не выполнялась. XML файлов XAML проверен на корректность отдельно.
